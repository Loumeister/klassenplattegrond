# Class Seating Chart Generator (Klassenplattegrond)

## Description
This program generates classroom seating charts from a list of student names. It can take input as a direct comma-separated list, a CSV file, or a TSV file. The output can be an Excel file (.xlsx) with separate "Teacher's View" and "Student's View" sheets, or a JPG image (.jpg) displaying both views. The layout is fixed to 30 student seats, arranged in three table blocks, with an optional teacher's position at the front.

## Features
*   **Multiple Input Sources**: Accepts names from:
    *   Comma-separated string.
    *   CSV file (names in the first column).
    *   TSV file (names in the first column).
*   **Flexible Output Formats**:
    *   Excel (.xlsx): Includes two sheets:
        *   "Teacher's View": Standard classroom layout.
        *   "Student's View": A 180-degree rotated view for students facing the teacher.
    *   JPG (.jpg): A single image containing:
        *   Teacher's View (top).
        *   Student's View (bottom, 180-degree rotated).
*   **Fixed Seating Layout**: Arranges students in a fixed layout of 30 seats:
    *   Three main table blocks.
    *   Each block consists of 5 columns of paired seats (5x2).
*   **Optional Teacher's Seat**: An optional teacher's name can be provided, which will be displayed at the front of the class in the diagrams.
*   **Randomized Seating**: Student names are shuffled before being placed in the chart.

## Installation

### Prerequisites
*   Python 3.x

### Steps
1.  **Clone the repository (optional)**:

## Usage
The script is run from the command line. Below is the help information generated by the script:

```text
usage: seating_chart_generator.py [-h] --input-type {list,csv,tsv}
                                  --output-format {excel,jpg} --output-file
                                  OUTPUT_FILE [--teacher TEACHER]
                                  input_source

Generate a seating chart from a list of names.

positional arguments:
  input_source          Path to the input file (CSV/TSV) or a comma-separated
                        string of names.

options:
  -h, --help            show this help message and exit
  --input-type {list,csv,tsv}, -t {list,csv,tsv}
                        Type of the input source.
  --output-format {excel,jpg}, -f {excel,jpg}
                        Desired output format.
  --output-file OUTPUT_FILE, -o OUTPUT_FILE
                        Name and path for the output file (e.g., chart.xlsx or
                        chart.jpg).
  --teacher TEACHER     Optional name of the teacher.
```

### Examples

1.  **Input from a comma-separated list, output to Excel, with a teacher:**
    ```bash
    python seating_chart_generator.py "Alice,Bob,Charlie,David,Eve,Fiona" -t list -f excel -o chart.xlsx --teacher "Mr. Harrison"
    ```

2.  **Input from a CSV file, output to JPG:**
    *(Assuming `sample_inputs/names.csv` exists with names in the first column)*
    ```bash
    python seating_chart_generator.py sample_inputs/names.csv -t csv -f jpg -o chart.jpg
    ```

3.  **Input from a TSV file, output to Excel, with many names (more than 30 will be truncated):**
    *(Assuming `sample_inputs/all_students.tsv` exists with names in the first column)*
    ```bash
    python seating_chart_generator.py sample_inputs/all_students.tsv -t tsv -f excel -o class_seating.xlsx --teacher "Ms. Davis"
    ```

### Input File Formats
*   **CSV/TSV Files**: The script expects student names to be in the first column of the CSV or TSV file. Empty rows or rows where the first column is empty will be ignored.

## Seating Layout Explained
*   **Student Seating**: The classroom layout consists of 30 student seats, arranged as three distinct table blocks. Each block has 5 columns, and each "column" is a pair of two seats (desk pair). So, each table block seats 10 students (5x2).
*   **Teacher's Seat**: If a teacher's name is provided, it is displayed at the "front" of the classroom.
    *   In the Excel "Teacher's View" and the top part of the JPG, this is at the top of the diagram.
    *   In the Excel "Student's View" and the bottom part of the JPG, this is at the bottom of the diagram (representing the teacher's position relative to a student looking "up" the chart).
*   **Student's View Rotation**: The "Student's View" is a 180-degree rotation of the "Teacher's View". This means:
    *   The table block that is at the "front" in the Teacher's View (e.g., Table 1) will appear as the "back" table from the student's perspective.
    *   Seats are mirrored accordingly. For example, the student in the top-left seat of Table 1 (Teacher's View) would appear in the bottom-right seat of the corresponding (now rearmost) table in the Student's View.

## iPhone Wrapper App (Carnaval der Dieren)

This repository now includes an iOS wrapper app at:

- `ios/CarnavalDerDierenApp`

### What it does

- Loads a locally scraped copy of the app from `WebMirror/index.html` if present.
- Falls back to the live URL `https://followamuse.nl/apps/carnaval-der-dieren/` when no local mirror exists.

### Scrape the web app

Use:

```bash
./scripts/scrape_followamuse.sh
```

This mirrors the page assets into:

- `ios/CarnavalDerDierenApp/CarnavalDerDierenApp/Resources/WebMirror`

### Generate and run the Xcode project

1. Install `xcodegen` if needed (`brew install xcodegen`).
2. Generate project files:

```bash
cd ios/CarnavalDerDierenApp
xcodegen generate
```

3. Open `CarnavalDerDierenApp.xcodeproj` in Xcode.
4. Build/run on an iPhone simulator or a physical iPhone.
